# Social Eyes brand system
Approved visual direction: a premium, privacy-first, mobile-native social discovery experience. Deep midnight navy surfaces, restrained cyan and violet accents, generous whitespace, crisp typography and an approachable eye mark.

**Product:** Social Eyes
**Tagline:** Discover. Connect. Belong.

The official native icon and adaptive foreground must be original 1024 × 1024 PNG files, tested for opaque RGB and transparent RGBA respectively. Never replace missing branding with placeholder files to bypass the release gate.

Accessibility: maintain readable contrast, visible keyboard focus, screen-reader labels, and a clear indication of opt-in visibility.
